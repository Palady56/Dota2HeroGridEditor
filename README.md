# Dota 2 Hero Grid Editor

Веб-приложение для рисования картинок из символов в сетке героев Dota 2 и экспорта готового файла `hero_grid_config.json`. Всё считается в браузере: сервер не нужен, аккаунт и интернет для самой работы тоже не обязательны (портреты героев подгружаются с CDN Valve).

**Открыть в браузере:** [https://palady56.github.io/Dota2HeroGridEditor/](https://palady56.github.io/Dota2HeroGridEditor/)

Сайт раздаётся с GitHub Pages бесплатно. Можно пользоваться сразу, без установки. Локальный запуск ниже — если хотите править код или работать офлайн.

## Возможности

- **Фото → символы.** Загрузите картинку, расположите её на сетке (масштаб, поворот, зеркало, инверсия). Контуры превращаются в символы `. - | / \` с живым превью. Есть готовые стили: контур, заливка фона, ASCII-полутона и другие.
- **Редактор сетки.** Кисть, ластик, фигуры (линия, прямоугольник, ромб, треугольник, овал), рамки вокруг блоков героев, блоки героев с портретами, отмена/повтор.
- **Сборка из файлов.** Несколько JSON-сеток как слои: двигать, масштабировать, поворачивать и объединять в одну.
- **Работа с файлом Dota.** Импорт существующего `hero_grid_config.json`, добавление своей сетки в него, проверка на ошибки (повторы героев, выход за край сетки).
- Автосохранение работы в браузере (фото само не сохраняется — его нужно загрузить снова).

## Как запустить у себя

Приложение — обычный сайт. Для разработки нужен Node.js, дальше всё ставится из папки проекта.

### 1. Поставить Node.js

Нужен **Node.js 18 или новее** (лучше LTS, сейчас 20 или 22).

1. Откройте [https://nodejs.org](https://nodejs.org) и скачайте LTS.
2. Установите с настройками по умолчанию (галочка «Add to PATH» должна быть включена).
3. Закройте и заново откройте терминал (PowerShell, Windows Terminal или командную строку).
4. Проверьте:

```bash
node -v
npm -v
```

Должны появиться номера версий, например `v22.11.0` и `10.9.0`. Если команда «не найдена» — Node не попал в PATH: переустановите его или перезагрузите компьютер.

### 2. Скачать проект

**Вариант A — Git** (удобно обновлять потом через `git pull`):

1. Поставьте [Git for Windows](https://git-scm.com/download/win), если его ещё нет.
2. В терминале:

```bash
git clone https://github.com/Palady56/Dota2HeroGridEditor.git
cd Dota2HeroGridEditor
```

**Вариант B — без Git:** на странице репозитория нажмите зелёную кнопку **Code → Download ZIP**, распакуйте архив и в терминале перейдите в эту папку:

```bash
cd путь\к\Dota2HeroGridEditor
```

В PowerShell полный путь может выглядеть так: `cd E:\Projects\DotaHeroIcon`.

### 3. Установить зависимости и запустить

В папке проекта выполните по очереди:

```bash
npm install
npm run dev
```

`npm install` скачает библиотеки в папку `node_modules` (нужен интернет, один раз).  
`npm run dev` поднимет локальный сайт. В терминале появится адрес, обычно:

```
http://localhost:5173
```

Откройте его в Chrome, Edge или Firefox. Остановить сервер — `Ctrl+C` в том же терминале.

Если порт 5173 занят, Vite сам предложит другой, например `5174` — берите адрес из вывода команды.

### 4. Полезные команды

Выполнять из папки проекта:

| Команда | Что делает |
|---|---|
| `npm run dev` | Режим разработки с автообновлением страницы |
| `npm test` | Прогон тестов |
| `npm run build` | Сборка в папку `dist/` |
| `npm run preview` | Показать уже собранный `dist/` локально |

После `npm run build` папку `dist/` можно открыть любым статическим хостингом — отдельный бэкенд не нужен.

### Если что-то пошло не так

- **`npm` не является внутренней или внешней командой`** — Node не установлен или терминал открыт со старым PATH. Переустановите Node LTS и откройте новое окно терминала.
- **Ошибка при `npm install`** — проверьте интернет и что вы в папке с `package.json`. Затем удалите `node_modules` и файл `package-lock.json` и повторите `npm install`.
- **Белая страница / ошибка в консоли браузера** — откройте инструменты разработчика (`F12`) и обновите страницу. Чаще всего помогает остановить сервер и снова выполнить `npm run dev`.
- **Портреты героев не грузятся** — нужен интернет до CDN Valve. Без сети вместо картинок будут цветные клетки с именами.

## Как пользоваться (кратко)

1. **Фото → символы.** Загрузите картинку, выберите стиль, при необходимости подвигайте фото и крутилки слева. Превью справа — то, что уйдёт в сетку.
2. **Редактор сетки.** Поправьте символы кистью, фигурами или ластиком. Блок героев (`T`) ставится кликом или перетаскиванием и прыгает по целым иконкам.
3. **Сборка из файлов.** Если нужно сложить несколько готовых JSON в одну картинку.
4. **Сохранить JSON** — скачается `hero_grid_config.json`. Либо **«В мой файл Dota…»** — выберите ваш текущий файл из Steam, приложение допишет сетку к вашим, не затирая остальные.

Работа автоматически сохраняется в браузере. Фото после перезагрузки вкладки нужно загрузить снова.

## Как положить сетку в игру

1. Полностью закройте Dota 2 (не сворачивайте — выйдите).
2. Найдите файл:

```
Steam\userdata\<ваш Steam ID>\570\remote\cfg\hero_grid_config.json
```

`Steam ID` — папка с цифрами внутри `userdata`. Если папок несколько, откройте ту, где есть `570\remote\cfg`. Типичный путь на Windows:

```
C:\Program Files (x86)\Steam\userdata\123456789\570\remote\cfg\hero_grid_config.json
```

3. Скопируйте этот файл куда-нибудь — это запасная копия ваших сеток.
4. Либо замените его файлом из приложения, либо в приложении нажмите **«В мой файл Dota…»** и выберите оригинал: текущая сетка добавится (одноимённая заменится), остальные останутся.
5. Запустите Dota 2 и откройте сетку героев.

Если после запуска Steam перезаписал файл старой копией из облака: в Steam у отчётов о облачных конфликтах выберите локальный файл. Надёжнее закрывать игру *до* замены файла.

## Стек

React 18, TypeScript, Vite, Vitest. Картинки обрабатываются в Canvas 2D и Web Worker, без серверной части.
