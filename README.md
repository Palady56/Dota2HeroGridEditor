# Dota 2 Hero Grid Editor

Веб-приложение для рисования картинок из символов в сетке героев Dota 2 и экспорта готового файла `hero_grid_config.json`.

> Проект в разработке, публичной версии пока нет.

## Возможности

- **Фото → символы.** Загрузите картинку, расположите её на сетке (масштаб, поворот, зеркало, инверсия) — контуры превращаются в символы `. - | / \` с живым превью.
- **Редактор сетки.** Кисть, ластик, фигуры (линия, прямоугольник, ромб, треугольник, овал), рамки вокруг блоков героев, блоки героев с портретами, отмена/повтор.
- **Сборка из файлов.** Несколько JSON-сеток как слои: двигать, масштабировать, поворачивать и объединять в одну.
- **Работа с файлом Dota.** Импорт существующего `hero_grid_config.json`, добавление своей сетки в него, проверка на ошибки (повторы героев, выход за край сетки).
- Автосохранение работы в браузере.

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # тесты
npm run build    # сборка в dist/
```

## Как положить сетку в игру

Файл сеток лежит в папке Steam:

```
Steam\userdata\<ваш Steam ID>\570\remote\cfg\hero_grid_config.json
```

Закройте Dota 2, сделайте копию файла, затем замените его сохранённым из приложения (или используйте кнопку «В мой файл Dota…», чтобы дописать сетку к своим).

## Стек

React 18, TypeScript, Vite, Vitest. Обработка изображений — Canvas 2D и Web Worker, без серверной части.
